# Harness 0.6.0

0.5.5の公開後に検証した自律化・文書設計の改善を正式配布する版です。
既存の実装・独立評価を引き継ぎ、配布metadataと正式更新の導線を整えました。

## 変更

- 小さく可逆な挙動変更は、担当Agentが直接修正・必要検証で完了できます。micro契約、3役、独立レビューを毎回必須にしません。
- 通常機能は短い計画と完成時の独立レビュー。高リスク操作は実行前の承認境界と実行後検証を維持します。
- 現在状態→必要な仕様/コード→理由や矛盾が必要な履歴、の順で読みます。全Sprint照合や定型文書群の無条件生成を開始条件にしません。
- 質問は既存資料と決定を確認してから、今回利用者が決める必要のある未決だけに絞ります。それが解決したら実装へ進みます。
- 既存repoの文書保守にpreview、変更前hash、原文backup、参照確認、再適用安全を持つupgradeを用意しました。初期化のno-overwriteと区別します。
- model/effortの既定継承、固有ルール、既存dirty、未承認の副作用に関する境界を維持します。

## 更新

既存のedition・marketplace名・導入scopeを確認し、下記の自分のeditionだけを実行してください。
ローカルcheckout登録の場合はGit marketplace更新でcheckoutは更新されません。既存変更を保存して正式releaseを取り込んでから再installします。

### Agentic Harness

```sh
codex plugin marketplace upgrade agentic-harness-local
codex plugin add harness@agentic-harness-local
codex plugin list --marketplace agentic-harness-local --json
```

Claude Codeで既存scopeがuserの場合:

```sh
claude plugin marketplace update agentic-harness
claude plugin update harness@agentic-harness --scope user
claude plugin list --json
```

### Yasashii Harness

Yasashiiが既に導入されているhostだけで実行します。Agentic利用中hostへ追加する操作ではありません。

```sh
codex plugin marketplace upgrade yasashii-harness
codex plugin add harness@yasashii-harness
codex plugin list --marketplace yasashii-harness --json
```

Claude Codeで既存scopeがuserの場合:

```sh
claude plugin marketplace update yasashii-harness
claude plugin update harness@yasashii-harness --scope user
claude plugin list --json
```

project/local等の導入は元と同じscopeを指定します。installed versionが0.6.0であることを確認し、新しいsessionで入口Skillの実pathと内容を確認してください。
既存session内の読み込み済み指示は自動で入れ替わりません。進行中の質問・Sprint・承認を保持して、新sessionまたは明示的な再読込へ引き継ぎます。
plugin更新だけで消費repo文書を再移行せず、model/settingsやcacheを手編集しません。

## 検証の範囲

実装の独立PASSは [源流](../feedback/sprint-003.md)、[増分](../feedback/sprint-003-incremental.md)、[下流](../feedback/sprint-003-downstream.md) に保持しています。
公開準備では固定候補との本文一致、version/metadata、下流合成、実配布物を確認します。
正式公開・各hostのinstalled更新・新sessionの実読込は別々に確認し、公開物が存在するだけでhost反映済みとは扱いません。
Windows実機と速度改善率の比較はこのreleaseで新たに計測していません。
